# Pomodoro Timer

A simple, single-file Pomodoro timer built with plain HTML, CSS, and JavaScript — no frameworks, no build tools, no dependencies.

## Features

- Focus, Short Break, and Long Break modes
- Auto-progresses through 4 focus sessions into a long break
- Circular progress dial that fills as time counts down
- Adjustable session lengths
- Start / Pause, Reset, and Skip controls
- Fully responsive and keyboard-accessible

## Running it locally

No installation or build step required.

1. Clone this repository
2. Open `index.html` directly in any browser (double-click the file, or drag it into a browser window)

That's it — everything runs client-side.

## Tech

- HTML for structure
- CSS for styling (custom properties for the color palette)
- Vanilla JavaScript for the timer logic (no libraries)
